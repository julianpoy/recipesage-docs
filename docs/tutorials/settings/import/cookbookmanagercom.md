---
title: Importing From CookBookManager.com
description: Import your recipes from CookBookManager.com into RecipeSage. Upload the YAML .zip archive exported from CookBookManager.com to transfer your collection.
---

You can import recipes exported from CookBookManager.com by uploading the export archive via the import page. RecipeSage accepts the CookBookManager.com YAML export, which is a `.zip` archive containing one `.yml` file per recipe.

[https://recipesage.com/app/settings/import/cookbookmanagercom](https://recipesage.com/app/settings/import/cookbookmanagercom)

To export your library from CookBookManager.com:

1. Open CookBookManager.com and go to the export option for your recipes.
2. Choose the YAML export format to produce a `.zip` archive of `.yml` files.
3. Save the resulting `.zip` file, then upload it via the RecipeSage import page linked above.
