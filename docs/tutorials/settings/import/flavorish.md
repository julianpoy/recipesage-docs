---
title: Importing From Flavorish
description: Import your recipes from Flavorish into RecipeSage. Upload the .zip archive exported from Flavorish to transfer your collection, including images.
---

You can import recipes exported from Flavorish by uploading the export archive via the import page. RecipeSage accepts Flavorish's export, which is a `.zip` archive containing a `manifest.json`, a `recipes` folder with one JSON file per recipe, and an `images` folder.

[https://recipesage.com/app/settings/import/flavorish](https://recipesage.com/app/settings/import/flavorish)

To export your library from Flavorish:

1. Open Flavorish and go to the **Account** tab.
2. Under **Import & Export**, choose **Export recipes** to produce a `.zip` archive of your recipes, images, and collections.
3. Save the resulting `.zip` file, then upload it via the RecipeSage import page linked above.

Each recipe's title, description, ingredients, instructions, times, servings, source, notes, nutrition details, and image are brought across. Categories, cuisines, and collections are imported as labels.
