---
title: Importing From Crouton
description: Import your Crouton recipes into RecipeSage. Upload the .zip archive of .crumb files exported from Crouton to transfer your collection.
---

You can import recipes exported from Crouton by uploading the export archive via the import page. RecipeSage accepts Crouton's bulk export, which is a `.zip` archive containing one `.crumb` JSON file per recipe.

[https://recipesage.com/app/settings/import/crouton](https://recipesage.com/app/settings/import/crouton)

To export your library from Crouton:

1. Open Crouton on iOS or macOS and go to the **Settings** screen.
2. Use the export option for your recipes (the exact label varies by Crouton version) to produce a `.zip` archive.
3. Save the resulting `.zip` file, then upload it via the RecipeSage import page linked above.
